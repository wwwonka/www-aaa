## Pièges (pour le prochain agent)
- **`tsc` en ligne de commande est intercepté** vers le vieux binaire homebrew (options `tsconfig`
  invalides). Typechecker avec `node ./node_modules/typescript/bin/tsc --noEmit` (TS 6.0.3 local).
- **La Gamepad API n'expose la manette qu'après une première pression bouton** (vie privée) : brancher
  ne déclenche pas `gamepadconnected`. `GamepadSource` ne traite que `mapping === "standard"`.
- **La réduction 2-sticks → 1 vecteur dans le hub est un adaptateur transport TEMPORAIRE** (SAB = 1
  vecteur). Split / dash chargé auront besoin des 2 sticks + du ring d'actions côté sim → contrat de
  contrôle élargi à venir. La `ControllerFrame` porte déjà les 2 sticks pleine fidélité.
- **Séquences/combos = côté `sim/`** (déterministe, sur le ring d'actions ordonné), jamais dans l'input.
